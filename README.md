## 概要
YMM4用のタイマープラグインです。
以下4つの機能があります。

1.現在時刻表示
システム時計から、「時:分:秒.ミリ秒」を表示。

2.ツール起動からの経過時間
最初から表示されていたらYMM4起動時からはかれます。

3.タイマー
分・秒を設定できます。

4.ストップウォッチ
ラップ機能もあります。
## 使用方法

YMM4を起動し、ツールから高性能タイマーをクリックするだけで起動は完了です。この時点で経過時間が加算されていきます。
タブから機能を選択できます。

## 注意

ツールのサイズを小さくすると上手く表示が出来ないです。
